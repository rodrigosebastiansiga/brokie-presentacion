# Material público

Esta carpeta debe contener únicamente imágenes o videos previamente revisados
para difusión pública.

No incorporar capturas de diagnóstico, calibraciones, planos, archivos CAD,
datos personales, direcciones de red ni pantallas que revelen parámetros
internos del prototipo.

## Material incluido

- `un_poco_como_funciona.mp4`: demostración general autorizada del prototipo.
